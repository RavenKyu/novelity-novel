```
기능 PR → develop            (PR에 라벨: feature / fix / breaking)
      ↓  Actions 탭에서 "Prepare release" 실행 (bump: auto | patch | minor | major)

      ↓  자동으로 main 대상 PR 생성 (본문 = 변경 내역), 필수 검사 실행
```

|------|----------------|----------------|
