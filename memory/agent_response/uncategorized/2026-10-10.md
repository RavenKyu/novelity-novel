레퍼런스에서 가져온 원칙은 세 가지입니다.
- PR 게이트는 base와 병합한 결과를 검사합니다.
- 같은 PR의 이전 실행은 자동으로 취소합니다.
- e2e는 필수 게이트에서 뺍니다. 불안정한 게이트는 우회를 습관으로 만들기 때문입니다.

러너는 레퍼런스의 self-hosted macOS 대신 `ubuntu-latest`를 씁니다. 우리 스택은 Linux 컨테이너라 맥이 필요 없습니다.

## pre-commit 훅 (`.githooks/pre-commit`)
- 레퍼런스처럼 커밋에 포함된 파일과 관련된 검사만 돌립니다.
  - core-api가 포함되면 vet과 test를 돌립니다.
  - web이 포함되면 check와 lint를 돌립니다.
  - e2e는 커밋에 포함된 spec과 `E2E_SPEC_FILES`로 지정한 spec만 돌립니다.
- 건너뛰려면 `SKIP_HOOKS=1`(전체) 또는 `SKIP_E2E=1`(e2e만)을 씁니다.
- 임시 git index로 3가지 경우를 확인했습니다. 실제 git index는 건드리지 않았습니다.
